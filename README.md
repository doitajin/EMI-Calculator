**FinSuite** is a production-grade, feature-rich financial calculation platform crafted with Next.js 15 App Router, TypeScript, and Tailwind CSS. It features a stunning, tactile **Neumorphic (Soft UI)** design system with full Dark/Light mode support, interactive D3/Recharts visualizations, and comprehensive SEO optimization.

</div>

## 🌟 Key Features

- **17+ Professional Financial Calculators**:
  - 🏠 **Mortgage & Home Loan**: Principal, interest, taxes, insurance, and amortization schedules.
  - 🚗 **Auto Loan**: Monthly payment, interest rates, and loan terms.
  - 📈 **Compound Interest & Investments**: Wealth projection charts and growth schedules.
  - 💰 **Retirement & College Savings**: 529 tuition planning and nest egg forecasting.
  - 💳 **Debt Payoff (Avalanche vs. Snowball)**: Strategic debt reduction planners.
  - 💱 **Currency Converter & Financial Unit Converter**: Real-time exchange rates and metrics.
  - 📊 **ROI, Net Worth, Inflation, Emergency Fund, EMI, Tax, and Savings Goals**.

- **Tactile Neomorphic Design System**:
  - Implemented with precise multi-layered exterior shadows and inset recessed wells.
  - Seamless Dark and Light mode color palettes with automated theme persistence.
  - Custom neumorphic scrollbars, toggle buttons, and floating interactive controls.

- **Interactive Visualizations**:
  - Dynamic charts powered by Recharts with custom tooltips and responsive scaling.

- **Fully Optimized for SEO**:
  - Unique high-volume keyword-optimized meta titles and descriptions for all calculator routes (Mortgage, Auto Loan, Compound Interest, etc.).

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Custom Neumorphic CSS Variables
- **Animations**: Motion (Motion for React)
- **Charts**: Recharts & D3
- **Icons**: Lucide React
- **State Management**: Zustand

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18+) and npm installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/finsuite.git
   cd finsuite
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Build & Production

To build the application for production:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
